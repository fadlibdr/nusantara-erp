## Catatan sumber data

- **49 lembar** dicetak dari basis data demo yang hidup di erp1 (salinan baca-saja).
- **16 lembar** (ditandai *seed segar*) tidak punya satu pun dokumen di data demo, jadi
  contohnya DIBUAT di basis data scratch lewat API aplikasi sendiri — setiap gerbang,
  penomoran, maker-checker dan prasyarat dilalui, bukan dilewati (RFQ → penawaran → penilaian
  berbobot → BAN → AWD dua tingkat; GRN diposting sebelum retur; ADS disetujui direktur; dst).
  Isinya masuk akal tetapi FIKTIF: BAST I pada progres 55 % tidak realistis, NTPN dan angka
  pada kewajiban/ekualisasi pajak adalah contoh, nama pihak lawan transmittal dikarang. BAST
  sengaja dibiarkan *submitted* (belum disetujui) karena menyetujuinya mengunci proyek demo.
- Tidak satu pun contoh ini ada di erp1 atau di basis data demo yang sebenarnya.
